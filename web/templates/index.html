    高活跃如何计算？
        
      
          
    1. 补齐日历日期，只统计“我＋对方”的消息，计算以当天为中心的七日平均消息量。
      2. 
          
    2. 用当前所选日期范围内均线的中位数作基准。在高于基准、附近七天至少三天有消息的日期中，取均线的 75% 分位数作为高点门槛。
      3. 
          
    3. 寻找包含高点的连续区间：区间内各日的附近七天仍需至少三天有消息；均线须高于基准，且不低于“高点门槛的一半”与基准中的较高者；还要求至少三天的实际消息量达到区间门槛并高于基准。
      4. 
          
    4. 有多个区间时选择双方消息总数最多的一段。允许短暂低谷，长度不固定；这只表示消息活跃程度。
