# 使用指南

[返回项目首页](../README.md)

## 安装与启动

按首页的「快速开始」安装 Python 3.12 64 位和依赖。日常使用双击项目根目录的 `启动微信分析.cmd`，保留启动窗口，浏览器会自动打开本地网页。

命令行启动方式：

```powershell
.\.venv\Scripts\python.exe web_app.py --open-browser
```

不加 `--open-browser` 时手动访问 `http://127.0.0.1:8501`。更换端口：

```powershell
.\.venv\Scripts\python.exe web_app.py --port 8502 --open-browser
```

关闭网页不会停止程序。在启动窗口按 Ctrl+C 或关闭该窗口可停止服务。

## 创建分析副本

展开页面顶部「本地数据库」，按顺序操作：

1. 确认微信版本。优先识别运行中的 `Weixin.exe`；识别失败时可手动填写。已验证版本为 **4.1.13.65**。
2. 输入当前账号目录或 `db_storage` 路径。例如：

   ```text
   D:\微信数据\xwechat_files\<账号>\db_storage
   ```

   路径支持中文和空格。不要选择微信程序的安装目录。
3. 点击「检测目录」，确认找到 `contact/contact.db` 和全部 `message/message_*.db`。
4. 点击「创建分析副本」。程序将必要数据库及已有的 WAL/SHM 复制到自己的工作区。
5. 保持对应微信账号登录，点击「提取数据库密钥」。每个数据库独立验证，页面只显示成功状态。
6. 点击「解密数据库」。全部数据库通过 `PRAGMA integrity_check = ok` 后，进入分析页面。

首次复制和解密可能耗时数分钟，取决于数据库大小。已有有效工作区时，下次打开会检查并复用；此时即使微信关闭，也可以分析已有副本。

**原始微信数据库只读。后续操作都针对工作区副本。**

## 选择联系人

默认只显示有可读取聊天记录的通讯录好友，并按最近聊天时间排序。可以关闭「只看有聊天记录的好友」，或者改为按备注 / 昵称排序。

选择框支持按备注、微信昵称或微信号搜索，也支持方向键、回车确认和 Esc 收起。备注优先作为主名称，微信昵称和微信号在第二行显示；没有自定义微信号时显示内部 ID。内部使用唯一的 `username` 区分联系人，重名不会合并。

页面显示的是该联系人在当前副本中的可用记录范围，不是整个账号的历史范围。程序会跨所有消息分片读取，没有固定的「2025 年以后」限制。

## 日期范围与统计口径

统一日期范围包含起止两天，会同步更新指标、消息类型、四张图和最长文字。各图也可单独选择日期；再次修改统一范围时，所有图表会重新同步。

日期框右侧的「全选日期」选择该联系人全部可读取日期：统一范围旁的按钮同步全部图表，本图旁的按钮只更新本图。

| 内容 | 日期如何影响结果 |
| --- | --- |
| 顶部指标、消息类型、最长文字 | 按统一日期范围统计 |
| 每日趋势、小时分布、热力图 | 按各自图表日期范围统计 |
| 累计消息量 | 日期只限制显示区间，累计仍从最早记录开始 |
| 汉字数、所有字符数、高频词 | 始终使用当前联系人的全部可读取历史 |

统一范围和每张图都有「跟随最新日期」开关。开启后，更新记录或重新打开时，截止日期会使用最新可读取日期；关闭后保持固定。修改结束日期会关闭对应范围的跟随，全选日期会重新开启。

跟随开关按账号和联系人自动保存。固定的日期范围若要跨重启保留，还需开启「界面设置 → 日期范围」。选择更早日期不会恢复数据库中不存在的消息。

## 四张图表

### 每日消息趋势

显示「我 / 对方 / 总计」，默认聚焦所选范围末尾的最近 30 天。滚轮缩放日期，按住左键拖动，也可使用底部滑条；「显示全部」展开当前所选日期范围。

红色「高活跃」区间可以通过图例显示或隐藏。算法只使用双方消息量，在当前图表范围内计算七日均线，以中位数为基准寻找包含较高峰值、至少有三个较活跃日期的连续区间，再选消息总数最多的一段。长度不固定，允许短暂低谷；页面中「高活跃如何计算？」列出完整门槛。这只是消息趋势提示。

### 累计消息量

显示双方及总计截至每天结束时的累计消息数。没有消息的日期保持水平；从最早可读取记录开始累加，切换日期或缩放不会重新归零。

默认展示所选范围全貌，也可切换到最近一个月。提示框显示完整整数，例如 `14,021 条`。累计图与顶部总消息的口径一致，包含系统及发送者未识别消息。

### 24 小时消息分布

查看 0–23 点的消息数量。通过下方日期轴滚轮缩放或拖动时，柱状图会按可见日期重新统计。

### 星期 × 小时热力图

行是周一至周日，列是 0–23 点，红色越深表示消息越多。上方日期框控制统计范围。

## 消息类型与文字统计

### 消息类型

默认只显示数量最多的三类，点击展开查看其余类型。占比始终以表内所有类型为分母，不因折叠改变。

系统、位置和名片不列入类型表。引用次数单独显示；引用回复按本次回复自身的内容归类，不重复增加总消息数。表情类型指表情包，文字中的表情符号仍计为文字。红包和转账只统计消息条数，不统计金额。

顶部总消息包含系统及发送者未识别消息，所以类型表合计可能与顶部总数不同，双方发送数量之和也可能小于总数。

### 文字总量与高频词

始终使用当前联系人的全部可读取历史，不跟随日期筛选或图表缩放。总计、我发送、对方发送分别显示：

- 汉字数：只计汉字，包含扩展汉字。
- 所有字符数：按 Python `len(content)` 计算，包含字母、数字、标点、表情和正文内空白。
- 高频词：使用本地 jieba 分词，显示前 10 个，过滤单字、常见虚词、标点、纯数字和网址。

只统计已确认双方发送的文字正文，排除拍一拍、系统和非文字消息。引用回复只统计本次正文，不包含被引用原文；普通文字中提到「拍一拍」仍计入。

词语旁的「忽略」会用后面的词补齐前十；在「已忽略的词」里可恢复。不影响字符统计。忽略词对所有联系人生效，自动保存在本机，更新数据库后仍保留。

首次计算可能需要等待。结果缓存在当前服务内存中；调整日期直接复用，切换联系人或更新数据后重新计算，不需要 GPU。

### 最长文字

默认折叠，展开查看前 20 条。按 Python 字符数排序，不是字节长度；显示排名、字符数、发送者、时间和内容，受统一日期范围影响。

## 更新聊天记录与项目升级

### 更新聊天数据

在「本地数据库」中点击「更新聊天记录」。程序沿用已有来源路径，重新复制、逐库验证密钥、解密及检查，成功后替换当前副本并刷新分析。

建议保持对应微信账号登录，更新期间暂停收发消息。失败时保留原有可用副本。开启跟随的日期范围会延长到最新记录；关闭跟随的历史范围保持不变。原本停在末尾的局部视图会跟随新记录，原本浏览的历史视图保持不变。

「复制时间」是文件复制时间，不是聊天记录的起止时间。副本不会实时更新。换账号或修正来源路径时使用「重新初始化」。

工作区包含 `active` 当前版本、`pending` 临时副本和最多一个 `previous` 上一版本；更新时需要额外磁盘空间，不会无限保存快照历史。

### 更新项目代码

先停止本地服务。如果使用 Git 克隆，在没有待保留代码修改时执行：

```powershell
git pull --ff-only
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

然后重新启动程序，在网页按 Ctrl+F5 刷新。更新项目代码不会自动更新聊天数据库，读取新消息仍使用「更新聊天记录」。不要用覆盖或清理整个项目目录的方式升级，以免误删本机工作区。

## 保存界面状态

右上角「界面设置」提供四个独立选项：主题、联系人、日期范围、图表缩放。默认关闭；开启后保存当前状态，之后自动更新；关闭某项会清除该项保存值。

设置存放在 `workspace/preferences.json`，更新数据不会覆盖它，同一台电脑的不同浏览器也可读取。联系人名单选项、跟随开关和忽略词独立自动保存，不受以上四项记忆开关控制。

该文件可能包含联系人标识及聊天词语，同样属于私密数据，不应分享。

## 常见问题

**找不到联系人库或消息库？**

确认选择的是微信账号目录或 `db_storage`，且里面存在 `contact/contact.db` 与 `message/message_*.db`，不要选择安装目录。

**未检测到 Weixin.exe，或者没有有效密钥？**

先登录对应账号，核对数据路径和版本。权限不足时检查两个程序的运行权限是否一致，必要时以管理员身份启动终端。

**解密或完整性检查失败？**

暂停微信收发消息后重新创建副本，并确认是否为已验证版本。失败结果不会覆盖已有正常副本。

**为什么刚收到的消息没有显示？**

先更新聊天记录，再检查日期筛选。若消息仍在 WAL 中、尚未写回主 DB，当前版本可能暂时读不到。

**为什么某位好友只有一小段日期？**

这是该好友在当前副本中的实际记录范围。请确认微信本地库保存了更早记录；导入历史后再更新副本。程序无法读取只在手机上或已删除的数据。

**窗口提示端口被占用？**

关闭旧服务，或用 `--port 8502` 换端口。升级代码后应先停止旧进程；重复双击只会打开旧进程的网页，不会重启它。

**遇到其他错误？**

页面会显示原因，日志保存在 `workspace/logs/app.log`。反馈时提供微信版本、操作步骤和经过脱敏的提示，不上传数据库、密钥、真实联系人或聊天正文。详见 [贡献指南](../CONTRIBUTING.md)。
